# ohda-manager

نظام ويب عربي لإدارة العُهَد واللوازم، مصمم للعمل أولاً على كمبيوتر ويندوز بقاعدة بيانات SQLite، مع إمكانية الدخول إليه من الهاتف على نفس الشبكة المحلية، ثم نقله لاحقاً إلى سيرفر/VPS.

## التقنية

- Next.js
- React
- Tailwind CSS
- Prisma ORM
- SQLite
- ExcelJS لاستيراد ملف العهدة الحالي من Excel

## ما تم تنفيذه

- إدارة المواد والوحدات وأرقام صفحات الدفتر القديم.
- عرض الرصيد الحالي لكل مادة ومكان وجودها اعتماداً على سجل الحركات، وليس على رقم مخزن يدوياً.
- المواقع والغرف والموظفون وربط الموظف بموقعه مع حفظ تاريخ تغيّر الموقع.
- سندات إدخال اللوازم وإخراج اللوازم متعددة المواد، مع المسودة والمراجعة ثم الاعتماد.
- بيانات مستند الإدخال: المورد، الفاتورة، تاريخها، لجنة الاستلام، مرجع التقرير، أمر الشراء، السعر الإفرادي والقيمة.
- سند العهدة الشخصية من محتويات غرفة الموظف، مع منع تكرار عهدة كمية سبق ربطها بموظف.
- طباعة سند العهدة على صفحة أو عدة صفحات من دون تحويل الصفحات إلى سندات مستقلة.
- قالب سند العهدة قابل للتعديل وله إصدارات؛ السند القديم يبقى على الإصدار الذي استُخدم له.
- جرد افتتاحي للمواد القديمة التي لا يوجد لها سند إدخال.
- تسجيل سندات إدخال وإخراج تاريخية من الدفتر القديم بوضع مرجعي لا يغيّر الرصيد الحالي.
- ربط جزء من رصيد البداية بسند إدخال تاريخي عند اكتشاف مصدره لاحقاً، من دون مضاعفة الرصيد.
- استيراد Excel الخاص بمركز الرمثا مع الاحتفاظ بالرصد الدفتري والموجود الفعلي والتوزيع على الغرف.
- سجل حركة لكل مادة وإظهار أماكن وجودها الحالية.
- نسخ احتياطية متسقة من SQLite أثناء التشغيل باستخدام `VACUUM INTO`.
- اختبارات آلية عبر GitHub Actions تشمل قاعدة البيانات، استيراد Excel، ترحيل الحركات، النسخ الاحتياطي وبناء Next.js.

راجع `docs/DATABASE_DESIGN.md` للتصميم التفصيلي.

## حماية البيانات

المستودع عام، لذلك لا يجب رفع ملفات العهدة أو قاعدة البيانات الفعلية إليه. الملفات التالية مستثناة من Git:

- `private-data/`
- ملفات Excel/CSV
- ملفات SQLite
- ملفات البيئة `.env`

## الإعداد على كمبيوتر ويندوز

بعد تنزيل المشروع، يمكن تشغيل إعداد كامل من PowerShell من داخل مجلد المشروع:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\windows-setup.ps1
```

إذا كان ملف الرمثا موجوداً في:

```text
private-data\عهدة الرمثا 2025.xlsx
```

يمكن إنشاء القاعدة واستيراده مباشرة أثناء الإعداد:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\windows-setup.ps1 -ImportRamtha
```

السكربت يقوم بتجهيز `.env`، تثبيت الحزم، إنشاء SQLite، توليد Prisma، استيراد الملف عند الطلب، ثم بناء نسخة التشغيل.

بعد الإعداد يكفي تشغيل:

```text
start-ohda.cmd
```

وسيظهر عنوان الاستخدام على الكمبيوتر وعنوان الشبكة المحلية الذي يفتح من الهاتف.

## استيراد عهدة الرمثا من Excel

تاريخ الجرد الافتتاحي المعتمد لبيانات ملف **عهدة الرمثا 2025.xlsx** هو:

```text
31/12/2025
```

ويمكن الاستيراد منفرداً بالأمر:

```bash
npm run import:ramtha -- "private-data/عهدة الرمثا 2025.xlsx" --date=2025-12-31
```

هذا التاريخ هو نقطة البداية الرسمية للمخزون في النظام. أي مستندات قديمة أقدم من هذه النقطة يمكن إدخالها لاحقاً كمستندات تاريخية `REFERENCE_ONLY`، وربط سندات الإدخال بما تبقى من رصيد البداية من دون إضافة الكمية مرة أخرى.

المستورد لا يفترض أن الرصيد الدفتري يساوي الموجود، ولا يسقط الصفوف الناقصة. أي اختلاف أو رقم مادة مفقود يحفظ كتحذير للمراجعة.

## الدخول من الهاتف على الشبكة المحلية

نسخة التشغيل تستخدم:

```bash
npm run start:lan
```

ويستمع التطبيق على جميع واجهات الشبكة. مثلاً إذا كان عنوان الكمبيوتر `192.168.1.50` يفتح الهاتف:

```text
http://192.168.1.50:3000
```

الهاتف لا يملك قاعدة منفصلة؛ جميع الأجهزة تستخدم SQLite الموجودة على كمبيوتر ويندوز.

### رمز الدخول

النظام محمي برمز دخول عند ضبط `OHDA_PASSWORD` في ملف `.env`. أي جهاز على الشبكة يُطلب منه الرمز مرة واحدة (الجلسة 30 يوماً)، وتغيير الرمز يُلغي كل الجلسات السابقة.

في برنامج ويندوز (Electron) يُنشأ رمز من 6 أرقام تلقائياً في أول تشغيل ويُحفظ في `ohda-config.json` داخل مجلد بيانات البرنامج، ويظهر مع QR لعنوان الشبكة في الصفحة الرئيسية على الكمبيوتر فقط. نافذة البرنامج نفسها لا تحتاج رمزاً.

## الجرد من الهاتف بملصقات QR

1. من «ملصقات QR» اطبع ملصقات الغرف وألصقها على الأبواب، واطبع ملصقات المواد (ملصق لكل مادة أو لكل قطعة حسب الكمية).
2. من الهاتف افتح «جرد غرفة» واضغط «مسح ملصق الغرفة».
3. اضغط «مسح ملصقات المواد»: كل مسح يضيف قطعة واحدة للكمية الفعلية، والمادة غير المسجلة في الغرفة تُضاف تلقائياً كزيادة.
4. ما تدخله يُحفظ تلقائياً على الهاتف حتى لو أُغلقت الصفحة أو انقطع الاتصال، ويُمسح بعد حفظ الجرد بنجاح.

ملاحظة: المتصفح يسمح بالكاميرا المباشرة فقط على HTTPS أو localhost. على عنوان الشبكة `http://192.168.x.x` يعمل المسح بالتقاط صورة للملصق. لتفعيل الكاميرا المباشرة في Chrome على أندرويد يمكن إضافة عنوان الكمبيوتر في `chrome://flags/#unsafely-treat-insecure-origin-as-secure`.

## الدخول من الهاتف من أي مكان (Cloudflare Tunnel)

بدون VPN على الهاتف وبدون فتح منافذ على الراوتر. الكمبيوتر يجب أن يكون شغالاً والبرنامج مفتوحاً، والبيانات تبقى عليه. الرابط HTTPS، لذلك تعمل كاميرا المسح المباشر على الهاتف.

**شرط:** يجب ضبط رمز الدخول (`OHDA_PASSWORD` أو رمز برنامج ويندوز)، والسكربت يرفض العمل بدونه.

### تجربة سريعة (بدون حساب ولا دومين)

شغّل `cloudflare-ohda.cmd`، أو:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\cloudflare-tunnel.ps1
```

يثبّت السكربت `cloudflared` عبر winget إن لم يكن موجوداً، ثم يظهر رابط مثل `https://xxxx.trycloudflare.com`. الرابط يتغير في كل تشغيل ويتوقف عند إغلاق النافذة.

### رابط ثابت مجاني بدون دومين (workers.dev)

رابط النفق المؤقت يتغير كل تشغيل، لكن يمكن جعل الهاتف يفتح دائماً نفس الرابط `https://ohda.<حسابك>.workers.dev` الذي يحوّله للرابط الحالي:

1. انشر `cloudflare/redirect-worker` على حساب Cloudflare المجاني (Worker باسم `ohda` + KV مربوط باسم `OHDA` + Secret باسم `UPDATE_SECRET`).
2. على كمبيوتر العهدة أنشئ الملف `%APPDATA%\OhdaManager\ohda-tunnel.json`:

```json
{ "workerUrl": "https://ohda.<حسابك>.workers.dev", "secret": "<نفس UPDATE_SECRET>" }
```

3. عند تشغيل `cloudflare-ohda.cmd` يُرسل الرابط الجديد تلقائياً، وعلى الهاتف تفتح الرابط الثابت دائماً. عند تغيّر النفق قد يُطلب رمز الدخول مرة أخرى.

### رابط ثابت يعمل دائماً (يحتاج دوماناً مضافاً على Cloudflare)

1. في لوحة Cloudflare: Zero Trust ← Networks ← Tunnels ← Create a tunnel (Cloudflared)، وانسخ الـ Token.
2. أضف Public Hostname مثل `ohda.example.com` يشير إلى `http://localhost:3000`.
3. يُنصح بإضافة Access Application على نفس العنوان مع سياسة One-time PIN على إيميلات محددة (مجاني حتى 50 مستخدماً)، فلا يصل أحد لصفحة النظام قبل تأكيد إيميله.
4. على كمبيوتر العهدة، من PowerShell كمسؤول:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\cloudflare-tunnel.ps1 -Mode Install -Token "<TOKEN>"
```

يعمل النفق بعدها كخدمة ويندوز مع كل تشغيل. للإزالة: `-Mode Uninstall`.

## النسخ الاحتياطي

يمكن الضغط على:

```text
backup-ohda.cmd
```

أو تشغيل:

```bash
npm run backup:db
```

وتحفظ نسخة متسقة داخل `private-data/backups/`. هذا المجلد خاص ومستثنى من GitHub.
