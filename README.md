# ohda-manager

نظام ويب لإدارة العُهَد واللوازم، مصمم للعمل أولاً على كمبيوتر ويندوز بقاعدة بيانات SQLite، مع إمكانية الدخول إليه من الهاتف على نفس الشبكة المحلية، ثم نقله لاحقاً إلى سيرفر/VPS.

## التقنية

- Next.js
- React
- Tailwind CSS
- Prisma ORM
- SQLite
- ExcelJS لاستيراد ملف العهدة الحالي من Excel

## المرحلة الحالية

تم البدء بطبقة البيانات قبل الواجهات، وتشمل:

- المواد والمواقع والغرف والموظفين.
- سندات الإدخال والإخراج والعهدة والإرجاع والنقل والتسويات.
- الجرد/الرصيد الافتتاحي للمواد القديمة التي لا يوجد لها سند إدخال.
- ربط جزء من رصيد البداية بسندات إدخال تاريخية يتم اكتشافها لاحقاً من الدفتر، من دون مضاعفة الرصيد.
- سجل حركة مركزي لحساب الرصيد الحالي ومكان المادة.
- استيراد ملف Excel الخاص بمركز الرمثا مع الاحتفاظ بالرصد الدفتري والموجود الفعلي والتوزيع على الغرف.
- قوالب طباعة قابلة للإصدار والتعديل مستقبلاً.

راجع `docs/DATABASE_DESIGN.md` للتصميم التفصيلي.

## حماية البيانات

المستودع عام، لذلك لا يجب رفع ملفات العهدة أو قاعدة البيانات الفعلية إليه. الملفات التالية مستثناة من Git:

- `private-data/`
- ملفات Excel/CSV
- ملفات SQLite
- ملفات البيئة `.env`

## الإعداد المحلي لاحقاً على ويندوز

بعد تنزيل المشروع وتشغيله على الكمبيوتر:

```bash
npm install
copy .env.example .env
npx prisma generate
npx prisma migrate dev --name init
```

قاعدة البيانات الافتراضية ستكون محلية على الكمبيوتر وفق `DATABASE_URL` في ملف `.env`.

## استيراد عهدة الرمثا من Excel

تاريخ الجرد الافتتاحي المعتمد لبيانات ملف **عهدة الرمثا 2025.xlsx** هو:

```text
31/12/2025
```

ضع الملف محلياً، مثلاً:

```text
private-data/عهدة الرمثا 2025.xlsx
```

ثم يتم الاستيراد بالأمر:

```bash
npm run import:ramtha -- "private-data/عهدة الرمثا 2025.xlsx" --date=2025-12-31
```

هذا التاريخ هو نقطة البداية الرسمية للمخزون في النظام. أي سندات إدخال أو إخراج أقدم يتم إدخالها لاحقاً كمستندات تاريخية وربطها برصيد البداية من دون مضاعفة الرصيد الحالي.

المستورد لا يفترض أن الرصيد الدفتري يساوي الموجود، ولا يسقط الصفوف الناقصة. أي اختلاف أو رقم مادة مفقود يحفظ كتحذير للمراجعة.

## الدخول من الهاتف على الشبكة المحلية

عندما تصبح واجهة التطبيق جاهزة، سيعمل الخادم على الكمبيوتر عبر:

```bash
npm run dev:lan
```

ثم يفتح الهاتف عنوان الكمبيوتر على الشبكة المحلية، مثل:

```text
http://192.168.1.50:3000
```

ولا توجد قاعدة بيانات منفصلة على الهاتف؛ جميع الأجهزة تستخدم قاعدة البيانات الموجودة على الكمبيوتر.
