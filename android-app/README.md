# تطبيق إدارة العهدة لأندرويد

تطبيق Android أصلي صغير (Java + Android WebView) يثبت كـ APK ويستخدم واجهة العهدة المشتركة مع نظام ويندوز دون تشغيل متصفح خارجي.

## المزايا

- تسجيل الدخول برمز نظام العهدة وحفظ الجلسة داخل التطبيق.
- جرد الغرف والمواد والمسح بالكاميرا عبر QR مع أذونات Android.
- عرض السندات وطباعة سند عهدة الموظف باستخدام نظام الطباعة المدمج بأندرويد؛ **لا يغيّر قالب الطباعة الموجود**.
- رابط HTTPS قابل للتغيير من زر «الاتصال»؛ الرابط الافتراضي: `https://ohda.hksalameh.workers.dev`.
- عرض حالة انقطاع الخدمة ومنع شهادات HTTPS غير الصالحة أو صفحات HTTP غير المشفرة.
- عدم وجود أي ملف SQLite أو مفاتيح/بيانات المركز داخل APK. الحركات المعتمدة تُحفظ في قاعدة بيانات كمبيوتر العهدة.

## الوصول من شبكة أخرى

الرابط الثابت يعتمد على Cloudflare Worker + Tunnel الموجودين مسبقاً في المشروع. يجب أن يكون برنامج ويندوز والخدمة والنفق شغّالين وأن يكون **رمز دخول قوي** مضبوطاً. إذا أعاد الرابط HTTP 503 فالتطبيق لا يستطيع المزامنة حتى تتوفر الخدمة. لا يُنصح بنشر نظام تجريبي دون حماية.

**الحد الحالي:** هذه نسخة Android أصيلة من حيث التثبيت والكاميرا والطباعة والإعدادات، لكنها عميل متصل بخدمة Windows، وليست قاعدة بيانات محلية مستقلة أو نظام مزامنة ثنائي الاتجاه بدون اتصال. تبقى مسودات الجرد المحلية داخل WebView عبر IndexedDB حسب سلوك الموقع.

## البناء والاختبار

- Gradle 8.13، Android Gradle Plugin 8.11.1، JDK 17 أو 21، Android SDK 35.
- من المجلد `android-app`: شغّل `gradle :app:assembleDebug :app:lintDebug`.
- الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk`.
- GitHub Actions: `Android APK CI` يرفع ملف APK للاختبار كـ Artifact.
- قبل الإطلاق النهائي: اختبر على هاتف حقيقي الكاميرا، تسجيل الدخول، الجرد، النقل، سند العهدة، الطباعة، انقطاع الإنترنت وعودة الخدمة، ثم أنشئ نسخة Release موقعة بمفتاح محفوظ خارج GitHub.

## حماية البيانات

لا تنقل قاعدة SQLite الحية إلى الهاتف. لا ترفع قاعدة المركز أو رمز الدخول أو مفاتيح التوقيع إلى GitHub. لا يحق لأندرويد اعتماد حركة مالية/مخزنية دون فحص الخادم.
